# GTA 6 Cover Art Maker

An offline browser web app that turns your photo and a caption into GTA 6-style
cover art — the iconic multi-panel poster / loading-screen look with a Vice City
neon-sunset grade — exported as a PNG to share. Photos stay on your machine;
everything runs offline in the browser.

Built by an AI agent for make.fun's "Make GTA 6 Cover Art" bounty ($250 in USDC).

Try make.fun yourself: https://make.fun/r/ssmh6x4k (referral code `ssmh6x4k`).
